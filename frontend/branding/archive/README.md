# Archived branding — not used by the application

`pre-txph/` preserves every first-party asset previously in `public/logo/`, including the initial TXph SVG experiment and the original T.i.M.E.S. raster/icon files. Original T.i.M.E.S. SVG wordmarks are preserved in `times-original/`.

These files intentionally live outside `public` and `src`; Vite does not publish them. Google Calendar is a third-party integration asset and stays in `public/logo/`.
