เอกสารนี้อธิบายว่าแอป "T.i.M.E.S." เก็บ ใช้ และปกป้องข้อมูลของผู้ใช้อย่างไร แอปนี้เป็นโปรเจกต์อิสระที่ไม่ได้เป็นส่วนหนึ่งของ Google หรือบริษัทใด

1. ข้อมูลที่แอปเข้าถึงและเก็บไว้

เมื่อเข้าสู่ระบบด้วยบัญชี Google แอปจะขอสิทธิ์และเก็บข้อมูลดังนี้:

ข้อมูล วิธีที่แอปใช้ เก็บไว้ที่ไหน
ข้อมูลบัญชี Google พื้นฐาน (ชื่อ, อีเมล, รูปโปรไฟล์) ใช้ระบุตัวตนผู้ใช้ในระบบ (ผ่าน Firebase Authentication) Firebase Authentication (Google Cloud)
ข้อมูลกิจกรรมใน Google Calendar แสดงผล และจัดการกิจกรรมในปฏิทินหลักตามที่ผู้ใช้สั่ง; สำหรับคำถามเกี่ยวกับตาราง แอปอาจอ่านรายการปฏิทินที่ผู้ใช้มองเห็นได้และกิจกรรมในช่วงเวลาที่เกี่ยวข้อง ข้อมูลต้นฉบับอยู่ใน Google Calendar และเรียกผ่าน backend เพื่อแสดงผลหรือใช้ตอบคำถาม แอปเก็บข้อมูลบางส่วนเพิ่มเติมสำหรับคลังกิจกรรมและการแจ้งเตือนตามรายละเอียดด้านล่าง
คลังกิจกรรมและร่างกิจกรรม เก็บรายการที่ผู้ใช้เลือกเข้าคลังหรือสร้างเป็นร่าง เพื่อนำกลับมาใช้งาน เช่น ชื่อ วันเวลา หมวดหมู่ tag สี และระยะเวลา Firestore แยกตามบัญชีผู้ใช้ รายการในคลังเป็นข้อมูลแยกจากกิจกรรมต้นฉบับใน Google Calendar
Reminder และข้อมูลแจ้งเตือนกิจกรรม จัดตารางแจ้งเตือน โดยเก็บชื่อกิจกรรม รหัสกิจกรรม เวลาเริ่ม/จบ หรือการตั้งค่า Reminder รวมถึงสถานะการส่งและตัวนับโควต้า Firestore แยกตามบัญชีผู้ใช้
การเชื่อม Telegram และประวัติข้อความ ใช้ chat ID ผูกบัญชีกับแชทที่รับแจ้งเตือน ส่งข้อความที่ผู้ใช้สั่ง และแสดงข้อความจากแชทบอทกับสถานะอ่านแล้วในเว็บ Firestore เก็บข้อมูลเชื่อมต่อ ข้อความ รหัสข้อความ และเวลา; ข้อความที่ส่งหรือรับผ่าน Telegram อยู่บนบริการ Telegram ด้วย
Google Calendar refresh token เชื่อมต่อ Google Calendar ต่อเนื่องโดยไม่ให้ผู้ใช้ยืนยันสิทธิ์ทุกครั้งที่ access token หมดอายุ Firestore (Google Cloud) ในเอกสาร private ของผู้ใช้ โดยเข้ารหัสแบบ AES-256-GCM ก่อนจัดเก็บ และเข้าถึงได้เฉพาะ backend
หมวดหมู่ชีวิตที่ผู้ใช้สร้าง (เช่น งาน, ส่วนตัว, สุขภาพ) จัดกลุ่มกิจกรรมเพื่อคำนวณสรุปรายสัปดาห์ Firestore (Google Cloud) — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
การผูกกิจกรรมกับหมวดหมู่ (activity ↔ category mapping) คำนวณสัดส่วนเวลาต่อหมวดหมู่ในสรุปรายสัปดาห์ Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
Tag ที่ผู้ใช้ตั้งเอง (free text) ค้นหากิจกรรมด้วย tag Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
สถานะล็อกกิจกรรม ป้องกันการแก้ไข/ลบกิจกรรมที่ผู้ใช้ล็อกไว้โดยไม่ตั้งใจ Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน

เบราว์เซอร์อาจเก็บข้อมูลแคช การตั้งค่า และประวัติการคุยกับผู้ช่วยใน local storage เพื่อใช้ต่อเมื่อเปิดเว็บอีกครั้ง การล้างข้อมูลเว็บไซต์จะลบข้อมูลในอุปกรณ์นั้น แต่ไม่ได้ลบข้อมูลบน Firestore, Google Calendar หรือ Telegram

2. สิทธิ์ (Scope) ที่แอปขอจากบัญชี Google

การลงชื่อเข้าใช้ด้วย Google ใช้ยืนยันตัวตนเท่านั้น การเชื่อมต่อ Google Calendar เป็นขั้นตอนแยกที่ผู้ใช้เลือกเอง เมื่อเชื่อมต่อ แอปขอสิทธิ์ต่อไปนี้:

  • https://www.googleapis.com/auth/calendar.events — อ่าน สร้าง แก้ไข และลบกิจกรรมเพื่อให้ Activity Mode sync กับ Google Calendar ได้
  • https://www.googleapis.com/auth/calendar.calendarlist.readonly — อ่านรายชื่อปฏิทินที่ผู้ใช้มองเห็นได้ เพื่อให้ฟีเจอร์คำถามเกี่ยวกับตารางเลือกบริบทปฏิทินได้ โดยแอปไม่แก้ไขรายการปฏิทิน

แอปไม่ขอสิทธิ์เข้าถึง Gmail, Google Drive หรือข้อมูล Google อื่นนอกเหนือจาก Calendar และข้อมูลบัญชีพื้นฐานสำหรับยืนยันตัวตน

3. การแบ่งปันข้อมูลกับบุคคลที่สาม

แอปไม่ขาย ไม่แบ่งปัน และไม่เปิดเผยข้อมูลผู้ใช้ให้บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาดหรือโฆษณา แอปใช้บริการต่อไปนี้เพื่อให้บริการ และส่งข้อมูลตามฟีเจอร์ที่ผู้ใช้เลือกใช้งาน:

  • Google Cloud / Firebase — สำหรับ Authentication และฐานข้อมูล Firestore
  • Google Calendar API — สำหรับ sync กิจกรรมปฏิทิน
  • Vertex AI (Google Cloud) — ปัจจุบันฟีเจอร์ Gemini เปิดทดสอบเฉพาะบัญชีนักพัฒนาที่ได้รับอนุญาต เมื่อบัญชีดังกล่าวใช้ AI ข้อมูลคำขอและบริบทกิจกรรมที่เกี่ยวข้อง เช่น ชื่อกิจกรรม ช่วงเวลา และชื่อปฏิทิน อาจถูกส่งไปประมวลผลเพื่อสร้างคำตอบหรือร่างกิจกรรม ผู้ใช้ทั่วไปยังใช้การสร้างกิจกรรมและคำถามสำเร็จรูปโดยไม่ส่งไป Gemini
  • Render.com — สำหรับรัน backend server ของแอป (Express.js)
  • GitHub Pages — สำหรับ hosting หน้าเว็บฝั่ง frontend
  • Telegram — เมื่อผู้ใช้เชื่อม Telegram และเปิดรับแจ้งเตือน แอปส่งข้อความแจ้งเตือน ซึ่งอาจมีชื่อกิจกรรม วันเวลา และรายละเอียด Reminder ไปยังแชทที่เชื่อมไว้ ข้อความที่ผู้ใช้กดส่งไป Telegram จากเว็บจะถูกส่งผ่านบอท และข้อความที่คุยกับบอทอาจถูกเก็บเป็นสำเนาเพื่อแสดงในแชท MR.Zettascale บนเว็บ

การประมวลผลข้อมูลบนบริการภายนอกเป็นไปตามเงื่อนไขและนโยบายของผู้ให้บริการนั้น รวมถึง นโยบายความเป็นส่วนตัวของ Telegram การเชื่อม Google Calendar ไม่ได้เชื่อม Telegram ให้โดยอัตโนมัติ

4. การเก็บรักษาและการลบข้อมูล

ข้อมูลที่เก็บใน Firestore เช่น หมวดหมู่ การผูกหมวดหมู่ tag สถานะล็อก การตั้งค่า คลังกิจกรรม Reminder ข้อมูลแจ้งเตือน และประวัติแชท จะเก็บไว้เพื่อให้บริการจนกว่าผู้ใช้จะลบผ่านฟีเจอร์ที่รองรับหรือขอให้ลบตามหัวข้อที่ 7 โดยไม่ได้รับประกันการลบอัตโนมัติเมื่อหยุดใช้งาน refresh token ของ Google Calendar จะถูกลบทันทีเมื่อผู้ใช้เลือก "ยกเลิกการเชื่อมต่อ" ในการตั้งค่าของแอป หากต้องการให้ลบข้อมูลอื่นทั้งหมดที่เกี่ยวข้องกับบัญชีของท่าน สามารถติดต่อได้ตามช่องทางในหัวข้อที่ 7

การลบกิจกรรมจาก Google Calendar ทำได้ผ่าน Google Calendar หรือคำสั่งลบกิจกรรมในแอปนี้ รายการที่เก็บเข้าคลังเป็นข้อมูลแยกต่างหาก และต้องลบจากคลังกิจกรรมด้วยหากไม่ต้องการเก็บไว้ การยกเลิกการเชื่อม Calendar ลบ credential ของการเชื่อมต่อ แต่ไม่ได้ลบคลัง, Reminder หรือประวัติแชททั้งหมดโดยอัตโนมัติ

ปุ่มเคลียร์แชทบนเว็บใช้ล้างประวัติผู้ช่วยในเว็บและสำเนาข้อความ Telegram ที่แอปเก็บไว้ ไม่ลบประวัติในแอป Telegram หากต้องการลบข้อความที่อยู่ใน Telegram ให้จัดการผ่าน Telegram ด้วย การปิดแจ้งเตือนไม่ใช่การลบข้อความที่ส่งไปแล้ว

5. ความปลอดภัย

  • การยืนยันตัวตนทั้งหมดผ่าน Firebase Authentication และ Google OAuth 2.0 — แอปไม่เก็บรหัสผ่านของผู้ใช้ไว้เอง
  • ข้อมูลใน Firestore แยกตามบัญชีผู้ใช้แต่ละคน (per-user) ผู้ใช้คนอื่นเข้าถึงข้อมูลของกันและกันไม่ได้
  • การเชื่อมต่อทั้งหมดระหว่างแอปกับเซิร์ฟเวอร์เข้ารหัสผ่าน HTTPS
  • refresh token ของ Google Calendar ถูกเข้ารหัสก่อนเก็บ และไม่ถูกส่งกลับไปยังเบราว์เซอร์

6. สิทธิ์ของผู้ใช้

ผู้ใช้สามารถ:

  • เพิกถอนสิทธิ์การเข้าถึงบัญชี Google ของแอปได้ทุกเมื่อ ผ่าน Google Account — Third-party access
  • ยกเลิกการเชื่อมต่อ Google Calendar ในการตั้งค่าของแอป เพื่อให้ backend ลบ refresh token ที่เก็บไว้และพยายามเพิกถอน token กับ Google
  • ขอให้ลบข้อมูลที่แอปเก็บไว้ใน Firestore ได้ตามหัวข้อที่ 7
