นโยบายความเป็นส่วนตัว

ปฏิทินของฉัน (times-the-calendar) — ปรับปรุงล่าสุด: 7 สิงหาคม 2569

เอกสารนี้อธิบายว่าแอป "ปฏิทินของฉัน" (times-the-calendar) เก็บ ใช้ และปกป้องข้อมูลของผู้ใช้อย่างไร แอปนี้เป็นโปรเจกต์อิสระที่ไม่ได้เป็นส่วนหนึ่งของ Google หรือบริษัทใด

1. ข้อมูลที่แอปเข้าถึงและเก็บไว้

เมื่อเข้าสู่ระบบด้วยบัญชี Google แอปจะขอสิทธิ์และเก็บข้อมูลดังนี้:

ข้อมูล วิธีที่แอปใช้ เก็บไว้ที่ไหน
ข้อมูลบัญชี Google พื้นฐาน (ชื่อ, อีเมล, รูปโปรไฟล์) ใช้ระบุตัวตนผู้ใช้ในระบบ (ผ่าน Firebase Authentication) Firebase Authentication (Google Cloud)
ข้อมูลกิจกรรมใน Google Calendar (ปฏิทิน "primary" ของบัญชีที่ล็อกอิน) แสดงผล, สร้าง, แก้ไข, ลบกิจกรรมตามที่ผู้ใช้สั่งในแอป (two-way sync) ไม่ถูกเก็บสำเนาไว้ที่เซิร์ฟเวอร์ของแอป — แอปเรียก Google Calendar API โดยตรงจากเบราว์เซอร์ของผู้ใช้ทุกครั้ง ข้อมูลกิจกรรมยังคงอยู่ใน Google Calendar ของผู้ใช้เท่านั้น
หมวดหมู่ชีวิตที่ผู้ใช้สร้าง (เช่น งาน, ส่วนตัว, สุขภาพ) จัดกลุ่มกิจกรรมเพื่อคำนวณสรุปรายสัปดาห์ Firestore (Google Cloud) — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
การผูกกิจกรรมกับหมวดหมู่ (activity ↔ category mapping) คำนวณสัดส่วนเวลาต่อหมวดหมู่ในสรุปรายสัปดาห์ Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
Tag ที่ผู้ใช้ตั้งเอง (free text) ค้นหากิจกรรมด้วย tag Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน
สถานะล็อกกิจกรรม ป้องกันการแก้ไข/ลบกิจกรรมที่ผู้ใช้ล็อกไว้โดยไม่ตั้งใจ Firestore — แยกเก็บตามบัญชีผู้ใช้แต่ละคน

2. สิทธิ์ (Scope) ที่แอปขอจากบัญชี Google

แอปขอสิทธิ์ https://www.googleapis.com/auth/calendar (อ่านและเขียนปฏิทิน Google Calendar) เพื่อให้ฟีเจอร์ two-way sync ทำงานได้ — สร้าง/แก้ไข/ลบกิจกรรมในแอปแล้วสะท้อนไปยัง Google Calendar จริงของผู้ใช้ทันที แอปไม่ขอสิทธิ์เข้าถึงปฏิทินอื่นที่ไม่ใช่ปฏิทิน "primary" ของบัญชีที่ล็อกอิน และไม่เข้าถึง Gmail, Google Drive, หรือข้อมูล Google อื่นใดนอกเหนือจาก Calendar และข้อมูลบัญชีพื้นฐานสำหรับยืนยันตัวตน

3. การแบ่งปันข้อมูลกับบุคคลที่สาม

แอปไม่ขาย ไม่แบ่งปัน และไม่เปิดเผยข้อมูลผู้ใช้ให้บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาดหรือโฆษณา ข้อมูลถูกส่งไปยังผู้ให้บริการโครงสร้างพื้นฐาน (infrastructure providers) ที่จำเป็นต่อการทำงานของแอปเท่านั้น ได้แก่:

  • Google Cloud / Firebase — สำหรับ Authentication และฐานข้อมูล Firestore
  • Google Calendar API — สำหรับ sync กิจกรรมปฏิทิน
  • Render.com — สำหรับรัน backend server ของแอป (Express.js)
  • GitHub Pages — สำหรับ hosting หน้าเว็บฝั่ง frontend

ผู้ให้บริการเหล่านี้ประมวลผลข้อมูลในฐานะผู้ให้บริการโครงสร้างพื้นฐานตามนโยบายความเป็นส่วนตัวของตนเอง ไม่ใช่เพื่อวัตถุประสงค์ของตนเอง

4. การเก็บรักษาและการลบข้อมูล

ข้อมูลที่เก็บใน Firestore (หมวดหมู่, การผูกหมวดหมู่, tag, สถานะล็อก) จะถูกเก็บไว้ตราบเท่าที่ผู้ใช้ยังใช้งานแอปอยู่ หากต้องการให้ลบข้อมูลทั้งหมดที่เกี่ยวข้องกับบัญชีของท่าน สามารถติดต่อได้ตามช่องทางในหัวข้อที่ 7

ข้อมูลกิจกรรมปฏิทิน (Google Calendar events) ไม่ได้ถูกเก็บสำเนาไว้ที่ฝั่งแอปเลย — การลบกิจกรรมทำได้โดยตรงผ่าน Google Calendar หรือผ่านแอปนี้ (ซึ่งจะสั่งลบที่ Google Calendar จริงทันที)

5. ความปลอดภัย

  • การยืนยันตัวตนทั้งหมดผ่าน Firebase Authentication และ Google OAuth 2.0 — แอปไม่เก็บรหัสผ่านของผู้ใช้ไว้เอง
  • ข้อมูลใน Firestore แยกตามบัญชีผู้ใช้แต่ละคน (per-user) ผู้ใช้คนอื่นเข้าถึงข้อมูลของกันและกันไม่ได้
  • การเชื่อมต่อทั้งหมดระหว่างแอปกับเซิร์ฟเวอร์เข้ารหัสผ่าน HTTPS

6. สิทธิ์ของผู้ใช้

ผู้ใช้สามารถ:

  • เพิกถอนสิทธิ์การเข้าถึงบัญชี Google ของแอปได้ทุกเมื่อ ผ่าน Google Account — Third-party access
  • ขอให้ลบข้อมูลที่แอปเก็บไว้ใน Firestore ได้ตามหัวข้อที่ 7
