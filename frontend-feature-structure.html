01 / OWNERSHIP

หนึ่งฟีเจอร์ มีเจ้าของชัดเจน

เมื่อแก้ Week Spine ให้เริ่มที่ features/activity/ ส่วนกำหนดเตือนและสถิติอยู่ใน features/reminder/ ไม่ต้องไล่ค้นทั้งโฟลเดอร์ components รวม

02 / CONNECTION

สองโหมดเชื่อมกันที่ app

app/ ส่งกิจกรรมและ callback ให้ Reminder Timeline เหมือนแนวทางปัจจุบัน โดย Activity ยังเป็นเจ้าของการแก้ไขกิจกรรม ช่วยเลี่ยงการ import วนระหว่างสองโหมด

03 / SHARED

ส่วนกลางมีเฉพาะของที่ใช้ร่วมจริง

ฟังก์ชันวันที่ ระบบภาษา และตัวเรียก HTTP อยู่ใน shared ส่วนกฎ reminder ถึงกำหนดหรือกฎวางกิจกรรมซ้อนอยู่กับฟีเจอร์เจ้าของ

shared ไม่ควร import กลับไปหา app หรือ features

04 / RUNTIME

แจ้งเตือนทำงานเหนือหน้าจอ

เป้าหมายในรอบ refactor คือให้ app เรียก runtime แจ้งเตือนจาก notifications โดยรับข้อมูล Activity และ Reminder เพื่อทำงานได้แม้สลับโหมด

ปัจจุบันยังเก็บ Reminder Mode mounted ไว้เพื่อให้วงรอบทำงาน การแยก runtime เป็นงานถัดไปหลังย้ายไฟล์สำเร็จ

05 / SCOPE

โครงนี้เป็นตัวอย่าง ไม่ใช่คำสั่งย้ายทันที

ชื่อไฟล์ที่ระบุชัดอ้างอิงไฟล์ที่มีจริง ส่วนโฟลเดอร์ api, runtime และ component ย่อยบางส่วนเป็นตำแหน่งที่เสนอให้แยกในอนาคต

ไฟล์ activity-mode.jsx รุ่นอื่นต้องตรวจจุดเรียกใช้ก่อนตัดสินใจย้ายหรือเลิกใช้ ไม่สรุปจากชื่อไฟล์เพียงอย่างเดียว

STEP 1

เก็บจุดเริ่มต้น

Build และบันทึก commit ก่อนย้าย ตรวจ dependency ของไฟล์ที่เกี่ยวข้อง

STEP 2

ย้ายทีละฟีเจอร์

รักษาชื่อไฟล์และ logic เดิม แก้ import แล้วตรวจหน้าจอและ build ทุกชุด

STEP 3

ค่อยแยกไฟล์ใหญ่

แยก API, CSS และ runtime หลังโครงใหม่ทำงานได้แล้ว ใช้ commit แยกจากการย้าย
