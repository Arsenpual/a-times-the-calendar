# Times The Calendar — ภาพรวมโปรเจกต์

> ปฏิทินที่สรุปชีวิตคุณให้อัตโนมัติทุกสัปดาห์ — ไม่ใช่แค่จดกิจกรรม แต่ช่วยให้เห็นภาพว่าเวลาไปอยู่ที่ไหนบ้าง

**สถานะ:** 🟢 Public Production — เปิดใช้งานจริง, ค้นเจอผ่าน Google Search ได้, ล็อกอินผ่าน Google ได้สาธารณะ

---

## หน้าตาระบบคร่าวๆ

| ส่วน | เทคโนโลยี | Hosting |
|---|---|---|
| Frontend | React + Vite | GitHub Pages |
| Backend | Node.js + Express | Render.com |
| ฐานข้อมูล | Firestore (แยกข้อมูลรายผู้ใช้) | Firebase |
| ล็อกอิน | Firebase Auth (Google) | Firebase |

**หลักการสำคัญ**: ตัวกิจกรรมจริง (ชื่อ/เวลา/ทำซ้ำ) อยู่ใน **Google Calendar โดยตรง** — แอปนี้ไม่เก็บสำเนา แค่เพิ่ม "ชั้นข้อมูลเสริม" (หมวดหมู่, tag, การล็อก) ทับไว้ผ่าน backend ของตัวเอง

---

## ฟีเจอร์ทั้งหมด

### 📅 ปฏิทินและกิจกรรม
- ซิงก์สองทางกับ Google Calendar แบบเรียลไทม์ (สร้าง/แก้/ลบ กระทบ Google Calendar จริงทันที)
- สร้างกิจกรรมทำซ้ำแบบกำหนดเอง — ทุก N วัน/สัปดาห์/เดือน, เลือกวันในสัปดาห์ได้ (เช่น จ-พ-ศ), จำกัดจำนวนครั้งสูงสุด 20 ครั้งหรือกำหนดวันสิ้นสุด
- รองรับกิจกรรมข้ามเที่ยงคืน แสดงเป็นบล็อกยื่นข้ามวันในไทม์ไลน์
- กิจกรรมที่ทับซ้อนเวลากันแสดงเรียงเป็นคอลัมน์ข้างกันอัตโนมัติ
- ลากปรับเวลากิจกรรมได้ตรงในไทม์ไลน์ (drag-and-drop) พร้อม context menu (คลิกขวา) สำหรับแก้ไข/ลบ/ทำสำเนา/ย้ายวัน/ล็อก

### 🏷️ หมวดหมู่ชีวิตและ Tag
- ตั้งหมวดหมู่ชีวิต (Life Areas) ได้เอง พร้อมสี — ผูกกับกิจกรรมแต่ละอันเพื่อดูสัดส่วนเวลา
- ติด tag แบบอิสระ (free-text) ได้หลาย tag ต่อกิจกรรม ค้นหากิจกรรมย้อนหลัง/ล่วงหน้าด้วย tag ได้ (ค้นในช่วง ±3 เดือน)
- ล็อกกิจกรรมสำคัญไม่ให้แก้ไข/ลาก/ลบโดยไม่ตั้งใจ — บังคับใช้ทั้งฝั่งหน้าเว็บและกฎความปลอดภัยของฐานข้อมูล (สองชั้น)

### 📊 สรุปรายสัปดาห์ (จุดขายหลัก)
- แผนภูมิวงกลมแสดงสัดส่วนเวลาต่อหมวดหมู่
- บอกวันที่ยุ่งที่สุดของสัปดาห์
- สร้างข้อความ insight ภาษาไทยอัตโนมัติ (เช่น "สัปดาห์นี้เวลาส่วนใหญ่อยู่ที่หมวดงาน")
- แสดงผ่าน flip-card สลับกับ mini-timeline ของวันที่เลือก

### 🖼️ Export
- ส่งออกไทม์ไลน์รายวันเป็นไฟล์ภาพ PNG เก็บไว้ดูโดยไม่ต้องเปิดแอป

### 🎨 การตั้งค่าและการแสดงผล
- **Dark Mode** — สลับธีมสว่าง/มืดได้ผ่านเมนูตั้งค่า
- **สองภาษา (ไทย/อังกฤษ)** — สลับได้ทั้งข้อความในหน้าเว็บและรูปแบบวันที่/เดือน/เลขสัปดาห์
- วันปัจจุบันเน้นด้วยเอฟเฟกต์ "บุ๋มลง" ให้สังเกตง่ายในมุมมองรายสัปดาห์

### ⌨️ การควบคุมด้วยคีย์บอร์ด
- ปุ่มลูกศรซ้าย-ขวาเปลี่ยนสัปดาห์ได้จากทุกจุดในหน้า (ไม่ต้องคลิกเลือกวันก่อน)
- ปุ่มลูกศรขึ้น-ลงย้ายโฟกัสระหว่างวันในสัปดาห์ พร้อมเปิด mini-timeline ของวันนั้นอัตโนมัติ
- คลิก/โฟกัสวันไหนก็เปิดดูไทม์ไลน์ย่อของวันนั้นทันที

### 🔐 ความปลอดภัยและสถาปัตยกรรมผู้ใช้หลายคน
- ล็อกอินด้วย Google ผ่าน Firebase Auth
- ข้อมูลแต่ละผู้ใช้แยกกันเด็ดขาดในฐานข้อมูล (`users/{userId}/...`) ตรวจสอบสิทธิ์ทุก request ด้วย Firebase ID token
- ผู้ใช้ใหม่ได้หมวดหมู่เริ่มต้น 4 อย่าง (งาน, ส่วนตัว, สุขภาพ, ครอบครัว) อัตโนมัติตอนล็อกอินครั้งแรก

### 📢 อื่นๆ
- แถบประกาศข่าวสารเลื่อนอัตโนมัติใต้หัวข้อ (ตอนนี้ยังเป็นข้อความคงที่ในโค้ด อยู่ระหว่างวางแผนเชื่อมกับ backend)

## งานค้างสำคัญที่ควรทำต่อ

1. **ยืนยันแอปกับ Google** — ผู้ใช้ใหม่ยังเห็นคำเตือน "แอปยังไม่ได้ยืนยัน" อยู่
2. **จำกัดอัตราการเรียกใช้ (Rate Limiting)** — ป้องกันการใช้งานเกินขอบเขตฝั่ง backend
3. **เฝ้าระวังปัญหา Cold Start** — เซิร์ฟเวอร์ฟรีของ Render อาจตอบช้า 10-30 วินาทีตอนไม่มีคนใช้งานนาน ๆ
