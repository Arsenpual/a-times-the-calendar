# Phase 1 — Activity Creation Skill

ดำเนินการ: 2026-09-14

## สิ่งที่ทำ

- แยก prompt, schema, examples, assumptions และ validator ไปที่ `backend/skills/activity-creation/`
- เติมวัน/เวลา/ระยะเวลาที่ขาดด้วยโค้ด โดยรักษาค่าที่ระบุไว้
- ตรวจวันจริง เวลาเริ่ม–จบ ขนาดข้อความ หมวดหมู่ tag และวันสิ้นสุดแบบ exclusive
- ส่งออก assumptions, tags และ recurrence: null ในร่างมาตรฐาน
- แสดง assumptions และแก้รายละเอียดในแชต รวมถึง tags
- ตรวจร่างที่แก้ด้วยมือผ่าน backend ก่อน Confirm เรียกเส้นทางบันทึกเดิม
- ล้างร่างหลังบันทึกสำเร็จ ป้องกันการกด Confirm ซ้ำขณะบันทึก
- แชตเต็มหน้าจอและแยกพื้นที่เลื่อนข้อความจากโควต้า/ช่องพิมพ์

## ขอบเขต

สร้างกิจกรรมเดี่ยวเท่านั้น การทำซ้ำยังไม่รองรับใน Phase 1 และ validator จะปฏิเสธ recurrence ที่ไม่ใช่ null
เป้าหมาย 1–3 ข้อความใช้เมื่อเจตนาชัดเจน หากชื่อยังไม่ชัดหลังสองคำถามจะขอให้ผู้ใช้ระบุชื่อเอง โดยไม่สร้างชื่อแทน
การนับรอบอ้างอิงประวัติสนทนาที่ frontend ส่งมา ไม่ใช่การจำกัดสิทธิ์ฝั่งเซิร์ฟเวอร์
การตีความภาษาของ Gemini ยังต้องทดสอบจริง; unit tests ตรวจค่าที่ผ่านการสกัดแล้ว

## การตรวจสอบ

`node --test backend/tests/activity-creation.test.js` — ผ่าน 25 เคส

`npm --prefix frontend run build` — ผ่าน (มีคำเตือนขนาด bundle เดิม)

ยังต้องทดลองเส้นทางจริง: Gemini → Edit detail → Confirm → Calendar ด้วยบัญชีที่เปิดสิทธิ์ AI
การทดสอบอัตโนมัติไม่ได้เรียก Gemini หรือสร้างกิจกรรมจริง
